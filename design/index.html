yougen Board + Room 页面设计

完整应用页面设计集：登录、注册、首页、Board、点击 Card 后详情、Room 聊天、Inbox、目录、管理、设备、审计、设置。整体参考 Trello 的工作台结构，但按 Contrix 协议补齐 Room/Message、权限裁剪、同步和并发收敛。

Open product prototype
高保真可点击应用原型

推荐从这里进入。单个静态应用壳包含登录、注册、首页、Board、Card 详情、Room、Inbox、目录、管理、设备、审计和设置，按钮会实际跳转。

Interactive 登录

Principal Server、DID/handle、设备会话、Passkey/OIDC/Device QR/dev login，以及登录后的 sync bootstrap。

Auth 注册

DID method、handle、profile、设备 proof、恢复策略和 invite accept 落点。

Account 应用首页

Space、最近 Board、Inbox、设备/同步健康、离线队列和启动状态。

Home Board + Room Workbench

横向 List 画布、Card 详情抽屉、primary Room 聊天、locked Room、并发 move 冲突和离线 pending 状态。

Board Space 概览

Space 下可见的 Boards、Rooms、最近活动、成员和 lazy links，强调 Space 是权限和同步边界。

Space 点击 Card 后详情

保持 Board 背景，打开右侧详情抽屉，覆盖字段编辑、Rooms、Chat preview、Activity 和 Audit。

Card Room 聊天

Room 列表、消息 timeline、composer、成员、history_visibility、E2EE 和上下文 lazy links。

Chat Inbox / Notifications

Mention、assignment、conflict、read marker、mute rules 和从通知进入 Card Room 的权限复核。

Inbox 目录发现

Spaces、Cards、Rooms、Actors 的搜索与 resolve，展示 readable、discoverable 和 locked lazy link。

Directory 联系人与 Actors

Actor 发现、联系人请求、信任状态、block；联系人关系不等于 Space 或 Room membership。

Actors Space 管理

Space metadata、join rule、Room external admission、invite、member grants 和危险生命周期。

Admin 设备与密钥

设备信任、SAS 验证、KeyPackage、one-time keys、to-device queue、push registration。

Devices 设备验证

QR/SAS 验证、新设备信任、MLS key package 和撤销影响说明。

Verify 同步与审计

Event Envelope、frontier、snapshot、state hash、authz explanation 和 Card move conflict。

Audit 设置与发布健康

本地账号配置、个人 View 偏好、主题语言、隐私和 release readiness。

Settings 页面规格与业务流程

覆盖创建 Board/List/Card、拖拽并发、Card primary Room、外部协作 Room、消息编辑撤回、离线同步和通知跳转。

Spec 设计总览

说明设计依据、协议边界和后续实现影响，包括从旧 channel 概念迁移到 Room/Message。
