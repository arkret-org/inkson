# yougen Interface Design

This folder contains static HTML product design prototypes for the Contrix client.

Open `index.html` directly in a browser. It is a single-file prototype that maps the protocol workflow surface to product screens:

- Account registration, login, device verification, and recovery readiness.
- Main Space timeline, encrypted composer, message state, and moderation actions.
- Contacts, requests, blocking, and privacy signals.
- Space lifecycle: create, metadata, policy, invite, add/remove members, archive, delete.
- Directory discovery for spaces, organizations, actors, and handles.
- Devices, keys, MLS group state, to-device messages, push registration.
- Sync/repo audit with cursors, commits, operations, backfill, snapshots, and conflicts.
- Settings, storage, release gates, and product readiness.

The prototype is intentionally dense and operational. It is meant to become the product shell, not a marketing page.
