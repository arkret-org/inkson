Claude Design — Contrix v1 客户端界面

基于 contrix-spec/spec/v1/zh 协议规范的客户端界面设计稿。覆盖 Identity / Space / Flow / Branch / View / Capability / Sync / E2EE / Applet / WebRTC 等所有协议平面，按桌面与移动两个版本组织。 详细的功能清单与业务流程说明见 README.md。

桌面版 / Desktop

登录

Passkey / OIDC / 设备扫码 / dev login，绑定 DID + Device。

desktop/login.html 新用户引导

选 DID method、绑定 handle、生成首设备密钥、设置恢复策略。

desktop/onboarding.html 工作台首页

Spaces、最近 Boards、Inbox 摘要、Sync 健康、离线队列。

desktop/home.html Space 概览

边界说明、boards / lists / flows、policy 摘要、成员预览。

desktop/space.html 看板 (Space kind=board)

横向 List、Flow card、拖拽 → cx.flow.move、视图切换、conflict 提示。

desktop/board.html Flow 详情 (synthesis)

字段、正文、关系、附件、活动、agent 结果落点。

desktop/flow-detail.html Flow 讨论 (discussion)

Branch-scoped 成员、E2EE banner、消息、回复、redaction。

desktop/discussion.html Inbox / Notifications

Mention、assignment、approval、locked lazy link、push 偏好。

desktop/inbox.html 发现 / Directory

Spaces / Orgs / Actors / Applets，区分 listed / restricted / invite_only。

desktop/directory.html 设备管理

设备列表、密钥包、push 注册、撤销、配对入口。

desktop/devices.html 设备验证

SAS emoji + 数字、QR 通道、cross-signing 状态。

desktop/verify-device.html 密钥备份与恢复

加密保险箱口令、社交恢复 (SSS)、recovery key、降级 PBKDF2。

desktop/recovery.html Space 管理

Discoverability / Join Rule / History Visibility、capability、moderation、federation、trust bundle。

desktop/space-admin.html 审计 / Sync

Event Envelope、frontier、snapshot、authz 决策、conflict 收敛。

desktop/audit.html Applet / Agent

Bot、Bridge、Ghost actor、Portal Space、Agent runtime 与 capability。

desktop/applets.html WebRTC 通话

SFU 多人会议、E2EE 标识、录制确认、TURN/媒体边界。

desktop/call.html 设置

Profile、隐私披露、通知、push、account lifecycle、release readiness。

desktop/settings.html

移动版 / Mobile

登录

主设备扫码 + Passkey + 首次同步进度。

mobile/login.html 首页

Inbox 概要、Spaces、recent flows、底部 5 项导航。

mobile/home.html 看板

单列焦点 + 横向 swipe，拖拽变为长按 reorder。

mobile/board.html Flow 详情

顶部 sheet 风格、字段紧凑、底部行动条。

mobile/flow-detail.html 讨论 / 聊天

消息流、attachment、@mention、E2EE 状态。

mobile/discussion.html Inbox

滑动归档 / 标记已读、push 脱敏说明。

mobile/inbox.html 设备 / 密钥

当前设备状态、SAS 验证、撤销丢失设备。

mobile/devices.html

业务流程速览

A. Onboarding

login → onboarding → recovery → home → space

 B. 日常协作

home → board → flow-detail → discussion → inbox

 C. 跨组织协作

space-admin → directory → inbox → audit

 D. 多设备 / 冲突

devices → verify-device → audit

 E. 实时会议

flow-detail → call → audit

 F. Applet / Agent

applets → space-admin → flow-detail → audit
