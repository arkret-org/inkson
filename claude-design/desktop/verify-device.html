SAS 只确认 device key 的人工信任。它本身不签发登录或 device authorization。

第 3 步 · 授权写入 + 密钥共享

① cx.device.authorized 把新设备公钥加入 device set 待你确认
② cx.device.cross_sign 主设备签名 device key，用于其他成员可信枚举 自动
③ MLS Welcome Acme Engineering / Launch Plan / Personal · 共 3 个 group 自动 · epoch++
④ secret storage 同步 从加密保险箱拉取 master key 加密 envelope 需口令
⑤ push token register 脱敏模式 background_sync_needed 自动
⚠️
跳过 SAS 等于跳过密钥信任。 如果你只完成扫码而拒绝 SAS，新设备只会拿到短期 cx.session.grant，无法读取 E2EE 历史，无法成为长期 device。
⚙️
验证产生的事件
cx.device.authorized · cx.device.cross_sign · cx.mls.welcome × N · 可选 cx.identity.recovery_attestation。所有事件都会写入你的 actor event chain，可在 audit 页核对。
