SAS（short authentication string）让两台设备肉眼比对一组随机 emoji 与数字。如果一致，说明握手中没有中间人。验证完成后才会签发 cx.device.authorized 与发送 MLS Welcome。 SAS (short authentication string) lets both devices compare random emoji + digits by eye. Matching means no MITM. Only after success do we sign cx.device.authorized and send MLS Welcome.

两台设备显示一致吗？Do both devices show the same?

同时在另一台设备打开「设备 → 完成验证」。两台设备应该显示完全相同的 7 个 emoji 与 3 组数字。 Open "Devices → Verify" on the other device. Both should show the exact same 7 emoji and 3 number groups.

协议事实 · SAS 绑定Protocol facts · SAS binds SAS 计算覆盖：双方 principal id / device id / verify key / transaction_id / chosen method / commitment / key / mac / transcript hash。任意一项篡改都会导致 mismatched_commitment 或 mismatched_mac。 SAS covers both principal ids, device ids, verify keys, transaction id, chosen method, commitment, key, mac, transcript hash. Tampering any of these triggers mismatched_commitment or mismatched_mac.
