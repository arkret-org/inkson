背景Context

在 board 上跨列拖动时，rank 字段使用 fractional indexing。当两个 actor 同时拖动到同一相邻槽位时，rank 会快速耗尽（rank_exhausted），需要触发重平衡。Drag-across-list uses fractional indexing for the rank field. When two actors drag to the same adjacent slot concurrently, rank space exhausts (rank_exhausted) and needs a rebalance.

目标Goals

  • 在 reducer 检测 rank_exhausted 后触发一次 cx.flow.rebalance 提案。Reducer detects rank_exhausted and proposes one cx.flow.rebalance.
  • 客户端 UI 显示「正在重排序」短暂态，不阻塞其他 flow 的拖动。Client shows a brief "reassigning" state, doesn't block other drags.
  • 并发的 cx.flow.move 必须用 cas_conflict 反馈，由 reducer 合并。Concurrent cx.flow.move returns cas_conflict; reducer merges.

Non-goals

  • 改变 board view projection 的 schema。Change board view projection schema.
